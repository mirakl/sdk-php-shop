# (L01) List locale codes and labels

```php
use Mirakl\MMP\Shop\Client\ShopApiClient;
use Mirakl\MMP\Common\Request\Locale\GetLocalesRequest;

$api = new ShopApiClient('https://your-marketplace.mirakl.net/api', 'your-api-key', 'your-shop-id');
$request = new GetLocalesRequest();
$result = $api->getLocales($request);
```
