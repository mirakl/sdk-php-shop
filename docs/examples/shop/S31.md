# (S31) Download documents for one or multiple shops

```php
use Mirakl\MMP\Shop\Client\ShopApiClient;
use Mirakl\MMP\Shop\Request\Shop\Document\DownloadShopDocumentsRequest;

$api = new ShopApiClient('https://your-marketplace.mirakl.net/api', 'your-api-key', 'your-shop-id');

$request = new DownloadShopDocumentsRequest('shop-001');
$request->setDocumentIds([42, 43])
    ->setTypeCodes(['SIRET', 'ID_CARD']);

$result = $api->downloadShopDocuments($request);

file_put_contents('/path/to/documents.zip', $result->getContents());
```
